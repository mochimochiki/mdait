# マーカーの書き方

mdait のマーカーをコードブロックで説明している文書。
コードブロックの中身は本文であって、ユニットの境目ではない。

## 基本の形

次のように書く。

```markdown
<!-- mdait 12345678 from:87654321 need:translate -->
## サンプル章

サンプルの本文。
```

行頭にあってもコードブロックの中なので、境目にならない。

## インデントで書いた場合

4つの空白で字下げしたコードブロックでも同じ。

    <!-- mdait aabbccdd -->
    ## 字下げしたサンプル

## 補足

コードブロックの外に書いたマーカーだけが境目になる。
