### ユニット確定機能（`fix` コマンド）

#### 機能概要
翻訳済みユニットを「確定」状態にする汎用コマンド。単独でも、TM登録や用語登録と組み合わせても使用可能。

**背景・価値：**
- 「このユニットは確定した」という状態を標準化
- 将来の用語登録、品質チェック等、各種確定処理の統一インターフェース
- ユーザー操作が明示的（プライバシー原則準拠）

#### 仕様

##### 1. `fix` コマンドの基本動作
- ユーザーが確定対象ユニット（単数・複数・ファイル・ディレクトリ）を指定→transコマンドと同様のユーザー体験
- マーカーに `fixed` フラグを付与
- オプション指定がなければ、フラグ付与のみ

**コマンド体系（VSCode UI と連携）：**
```json
{
  "mdait.fix.unit",       // ユニット単位（UI: CodeLens)
  "mdait.fix.file",       // ファイル単位（UI: Status View)
  "mdait.fix.directory"   // ディレクトリ単位（UI: Status View)
}
```

##### 2. オプション（組み合わせ可能）
```
mdait fix [--tm] [--terms] <path>
```

- **`--tm`**：同時に `fix --tm` ロジックを実行（将来機能。いったん実処理は何もなしで実装）
  - 指定ユニットの訳文を文単位に分割し、TMX に登録
- **`--terms`**：同時に用語登録ロジックを実行（将来機能。いったん実処理は何もなしで実装）
  - 指定ユニットから新用語を抽出、用語集に登録
- デフォルトのオプションは設定ファイルで指定可能。

##### 3. CodeLens との統合
- 未確定（`fixed` なし）ユニット → CodeLens に「確定する」アクション表示
- アクション名でオプション状態も示す（確定する tm:- term:- など）→オプション変更の自然な動線も用意
- デフォルト：`fix` のみ実行（オプションなし）
- 将来オプションが増えることも考慮

##### 4. 確定状態の管理
- マーカー形式：`<!-- mdait {hash} [from:{hash}] [need:{flag}] [fixed] -->`
- ユニット内容（`hash`）が変更されると消える（改定時には再確定が必要）

#### 設計時の重点検討項目
- **UI/UX**：ステータスパネル・CodeLens の「確定」アクション表示・制御（transのUXとの整合性）
- **冪等性**：`fix` 重複実行時の動作（既に `fixed` なら何もしない）
- **エラーハンドリング**：オプション実行時の個別失敗時の処理
