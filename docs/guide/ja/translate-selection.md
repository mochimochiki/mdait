# Translate Selection — 選択テキストをその場で即時翻訳する

正式な翻訳管理（マーカー・TM・ステータス）を一切変更せず、選択したテキストの直下に訳文を追記するオンデマンド翻訳コマンドです。

> **重要:** `trans` コマンドと違い、マーカー・ステータス・TM は一切変更しません。

---

<!-- mdait fee9527d -->
## 使い方

<!-- mdait b06b5279 -->
### コマンドパレット

1. 翻訳したいテキストをエディタで選択
2. `Ctrl+Shift+P` → `mdait: Translate Selection` を実行
3. 翻訳結果が選択範囲の**直下の行**に追記される

<!-- mdait bb3c22f0 -->
### 右クリックメニュー

1. 翻訳したいテキストをエディタで選択
2. 右クリック → **「Translate Selection (mdait)」** をクリック
3. 翻訳結果が選択範囲の**直下の行**に追記される

> 右クリックメニューの項目は**テキスト選択中のみ**表示されます。

## 翻訳方向の自動推定

現在開いているファイルのパスを `transPairs` の `sourceDir` / `targetDir` と照合して翻訳方向を自動決定します。

| 状況 | 動作 |
|---|---|
| 該当ペアが 1 つ | 自動でその方向で翻訳 |
| 該当ペアが複数 | 選択 UI を表示してユーザーが選択 |
| 該当ペアが 0 | エラー「翻訳ペアが見つかりません」を表示 |

**例:** `transPairs` が以下の場合

```json
[
  { "sourceDir": "docs/ja", "targetDir": "docs/en" },
  { "sourceDir": "docs/en", "targetDir": "docs/zh" }
]
```

`docs/ja/` 配下のファイルを開いていれば `ja→en` が自動選択されます。  
`docs/en/` は 2 つのペアに該当するため、方向選択 UI が表示されます。

## 用語集との連携

`trans` コマンドと同じ用語注入プロンプトを使用します。`.mdait/terms.csv`（`terms.filename` で変更可）の用語集が有効であれば、選択翻訳にも自動的に適用されます。

```
選択テキスト ──→ [用語集注入プロンプト] ──→ AI ──→ 訳文
```

`trans` コマンドで蓄積した用語集がそのまま活きるため、用語の統一感を維持できます。

## 制限事項

| 項目 | 動作 |
|---|---|
| マーカー | 変更しない |
| ステータス（`need` フラグ）| 変更しない |
| TM（翻訳メモリ） | 登録しない |
| 用語集 | 更新しない（注入のみ） |
| 翻訳結果の保存 | ファイルへの追記のみ |

選択翻訳は**ワンショットの補助ツール**です。正式な文書翻訳は `trans` コマンドを使ってください。

## よくある注意点

**Q. 翻訳結果が意図しない場所に追記された**  
→ 追記位置は「選択範囲の最終行の直下」です。選択範囲が行末まで含まれているか確認してください。
※現状、翻訳完了時に選択範囲が変更されていると追記位置も変わるため、翻訳中は選択を維持することを推奨します。

**Q. 右クリックメニューに項目が表示されない**  
→ テキストが選択されていない状態ではメニューに表示されません。テキストを選択してから右クリックしてください。

**Q. 「翻訳ペアが見つかりません」と表示される**  
→ 現在開いているファイルが `transPairs` のどの `sourceDir` / `targetDir` にも含まれていません。設定を確認するか、`transPairs` を追加してください。

**Q. 用語集が反映されない**  
→ `.mdait/terms.csv`（または `terms.filename` で指定したパス）に用語ファイルが存在するか確認してください。用語集の設定は [用語集ガイド](term.md) を参照してください。
